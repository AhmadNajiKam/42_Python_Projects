# 42 Python Projects

> Python curriculum projects from [42 School](https://www.42network.org/) — functional programming, data validation, file I/O, typing, and more.

📖 **[Documentation Site →](https://ahmadnajiKam.github.io/42_Python_Projects/)**

---

## Projects

| Folder | Theme |
|---|---|
| `FuncMage` | Lambdas, HOF, closures, decorators |
| `CosmicData` | Pydantic v2 data modelling |
| `DataArchivist` | File stream management |
| `DataDeck` | Data structures & comprehensions |
| `DataQuest` | Generators & iterators |
| `TheCodex` | Typing & Protocols |
| `TheMatrix` | Structural subtyping & generics |
| `CodeCultivation` | OOP fundamentals |
| `CodeNexus` | Module system & imports |
| `GardenGuardian` | Composition & ABCs |
| `GrowingCode` | Class-based iterators |

## Docs

The docs site includes:

- **Tutorials** — step-by-step walkthroughs (decorators, Pydantic modelling)
- **How-To Guides** — submitting exercises, running tests, debugging tracebacks
- **Reference** — project catalogue, Python concepts cheatsheet, 42 style rules
- **Project Deep-Dives** — design notes for FuncMage, CosmicData, DataArchivist, TheMatrix
